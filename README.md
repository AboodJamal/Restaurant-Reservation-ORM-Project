# Restaurant Reservation System

This is a .NET Core application designed to manage restaurant reservations, including customer information, employee data, orders, menu items, and tables. The application uses Entity Framework Core for database interactions and follows best practices in architecture and design.

## Features

- **Customer Management**: Customers can make reservations, view their past reservations, and manage their information.
- **Reservation Management**: Employees can view, create, update, and delete reservations.
- **Order Management**: Orders can be placed during reservations, with menu items being associated with each order.
- **Employee Management**: Employees are assigned to restaurants and can manage reservations and orders.
- **Menu Items**: Restaurants can define and manage their menu items, including descriptions and prices.
- **Revenue Calculation**: The system can calculate the total revenue generated by a restaurant, as well as average order amounts for employees.

## Technologies Used

- .NET Core 5.0+
- Entity Framework Core
- SQL Server
- C#
- LINQ
- Asynchronous Programming
